# PowerWatch — графік відключень світла для Windows

PowerWatch показує графік погодинних відключень електроенергії в підтримуваних регіонах України. Обери свій регіон і чергу, щоб бачити, коли за графіком вимкнуть або відновлять світло.

## Що вміє PowerWatch

- **Показує графік на сьогодні й завтра.** Зелені картки позначають години зі світлом, червоні — години відключення. Поточний інтервал виділено.
- **Показує зворотний відлік** до найближчого вимкнення або відновлення світла за графіком.
- **Попереджає перед вимкненням і відновленням.** За замовчуванням системне сповіщення Windows надходить за 5 хвилин. Час попередження можна змінити в межах від 1 до 120 хвилин. У налаштуваннях також можна вимкнути звук і перевірити сповіщення.
- **Повідомляє про зміни графіка.** Якщо для обраної черги змінили вже опублікований графік, сповіщення покаже попередні й нові години. Про публікацію графіка на завтра надходить окреме сповіщення.
- **Оновлює графік кожні 5 хвилин** у фоновому режимі. Черга зберігається окремо для кожного регіону.
- **Працює в області сповіщень Windows.** Колір значка показує стан за графіком, а один клік відкриває вікно програми. Автозапуск можна ввімкнути під час встановлення.
- **Дозволяє змінювати оформлення.** Можна налаштувати кольори фону, тексту й карток або повернути стандартні кольори.
- **Оновлюється через GitHub.** Кнопка «Оновлення програми» перевіряє наявність нової версії. Її можна встановити зі збереженням налаштувань.

## Обмеження

- PowerWatch показує планові відключення за даними «Світло+». Фактичний стан електромережі та аварійні відключення поза графіком програма не відстежує.
- Графік на завтра з’являється після публікації в джерелі та наступної перевірки.
- Для оновлення графіка й отримання сповіщень потрібні інтернет, увімкнений комп’ютер і запущена програма.
- Сповіщення про зміну графіка надходять, коли програма має попередній графік для порівняння. Після запуску вона показує актуальні години.
- Показ банерів і відтворення звуку залежать від налаштувань сповіщень Windows.

## Встановлення

Завантаж `PowerWatch-Setup.exe` з останнього випуску PowerWatch на GitHub і запусти його. Під час встановлення можна вибрати, чи відкривати програму одразу та чи запускати її разом із Windows.
